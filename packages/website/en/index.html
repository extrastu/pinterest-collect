Features

Browse, get recommendations and save in one panel

Not a website in an iframe — a Pinterest workspace rebuilt as a native Harness panel: recommendations from your account, saves on your machine.

Personalized feed

Reads your own Pinterest home feed after sign-in, with infinite scroll and a one-click refresh for a new batch.

Saves in one screen

Multiple boards, search and a draggable divider on the left; hit ♥ on the right and it appears instantly.

A detail page, not a modal

Large image, description and author, with more like this underneath; going back preserves your scroll position.

Your account page

Click the avatar to browse the pins you made on Pinterest, with infinite scroll and save/open actions.

Two-column settings

Section list on the left, details on the right: appearance (system / light / dark) and language (Chinese / English).

Privacy first

The session stays on this machine (mode 600) and can be cleared anytime; the plugin only reads Pinterest and never writes back.

How it works

Three steps to start

After installing, a new icon appears in the sidebar — that is the two-pane workspace.

  1. Install the plugin

    Install from GitHub with plugin_manager, restart Harness once and refresh the page.

  2. Sign in to Pinterest

    Use the one-click clean Chrome window (Google sign-in works) or paste cookies by hand; the feed appears right away.

  3. Start saving

    Browse the feed, search or paste a link; hit ♥ to save, open a pin for details and more like this.

Install

One command into Harness

You need DeepSeek Harness (desktop or web) with a plugin-capable profile. Install straight from GitHub — no clone needed:

  • After installing, restart Harness once and refresh the page;
  • To hack on the code, clone the repo and install the repository root by absolute path;
  • Full instructions, scripts and tests live in the repository README.
plugin_manager 
plugin_manager {
  action: "install_bundle",
  target: "github:extrastu/pinterest-collect"
}

// restart Harness once and refresh; use the local repo path for development

Data & privacy

Your account, your machine

The plugin never handles your password and never uploads your saves to a third party.

Saves stay local

Written to ~/.dsh/pinterest-collect/collection.json; back it up or inspect it anytime.

Session mode 600

The cookie lives in session.json on this machine; signing out deletes it.

Dedicated Chrome profile

One-click login uses its own profile and never reads your everyday browser session.

Read-only fetching

Requests only go to pinterest.com / pinimg.com; nothing is written back or uploaded.

FAQ

Things you may ask

Which platforms are supported?

DeepSeek Harness desktop and web builds on macOS, Windows and Linux. One-click login requires Chrome (or Chromium / Edge / Brave) on the machine; without Chrome you can paste cookies manually instead.

Are saves synced to my Pinterest account?

No. Saves are stored locally at ~/.dsh/pinterest-collect/collection.json and are not written back to your Pinterest account. Each pin detail page has an “Open on Pinterest” link so you can save it there manually.

Why not embed pinterest.com in an iframe?

Pinterest sends X-Frame-Options: SAMEORIGIN, so browsers refuse any cross-origin iframe. The plugin fetches Pinterest data in the Host half and renders a browsing UI in React, which looks embedded but is a native panel.

Google says “this browser or app may not be secure”. What now?

That was caused by launching Chrome with a debugging port in earlier versions. v1.2 uses a two-phase login where the sign-in window has no debugging flags; update to the latest version and restart Harness.

Can I use it without signing in?

Yes. Search, browsing and saving work without an account; the personalized feed only appears after you sign in to Pinterest.

Where is my data stored, and how do I sign out?

Saves and the session live under ~/.dsh/pinterest-collect/; the session file has mode 600. You can sign out from the panel at any time, which only deletes the locally stored cookie.
